# Loja do Bairro - Kanban

Quadro Kanban para organizar o desenvolvimento do site da Loja do Bairro.

## Colunas
Backlog, Ready, In progress, In review e Done.

## Regra de WIP
O limite é de 3 itens simultâneos na coluna In progress. Um novo item só pode entrar em In progress quando outro sair, seja para In review ou para Done. O GitHub apenas avisa quando o limite é excedido (a coluna fica vermelha), então a regra é respeitada pela equipe.
